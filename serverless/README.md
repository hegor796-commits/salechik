# Безопасная отправка заявок (прокси для Telegram)

## В чём проблема

Сейчас форма заявки отправляет сообщения прямо в Telegram, а **токен бота лежит
в коде страницы** (`index.html`, `contacts.html`). Любой, кто откроет исходный
код сайта, увидит этот токен и сможет отправлять сообщения от имени бота или
читать входящие. Для сайта-витрины это терпимо, но лучше исправить.

Полностью спрятать токен на статичном сайте нельзя — нужен маленький «посредник»
на сервере. Файл `telegram-proxy.js` — как раз такой посредник. Он бесплатный
(Cloudflare Workers) и разворачивается за 10 минут.

## Что делать прямо сейчас (обязательно)

Токен уже попал в открытый код и историю Git, поэтому его нужно **сменить**:

1. Откройте в Telegram чат с **@BotFather**
2. Команда `/revoke` → выберите бота → получите **новый токен**
3. Старый токен сразу перестанет работать

Дальше — либо вписать новый токен обратно в код (быстро, но снова видно всем),
либо развернуть прокси (правильно, токен спрятан). Инструкция ниже.

## Как развернуть прокси (Cloudflare Workers, бесплатно)

1. Зарегистрируйтесь на **https://dash.cloudflare.com** (бесплатно)
2. Слева: **Workers & Pages** → **Create** → **Create Worker**
3. Дайте имя, например `kurferma-proxy` → **Deploy**
4. Нажмите **Edit code**, удалите содержимое и вставьте весь код из
   `telegram-proxy.js` → **Deploy**
5. Откройте **Settings → Variables and Secrets** и добавьте:
   | Имя | Значение |
   |---|---|
   | `TG_TOKEN` | новый токен от BotFather |
   | `TG_CHAT` | `1781734613` (ваш chat_id) |
   | `ALLOW_ORIGIN` | адрес сайта, напр. `https://xoxloff-farm.ru` |
6. Скопируйте адрес воркера (вида `https://kurferma-proxy.ВАШ-АДРЕС.workers.dev`)

## Как переключить сайт на прокси

В файлах `index.html` и `contacts.html` найдите строку:

```js
const ORDER_ENDPOINT = '';
```

Впишите туда адрес воркера:

```js
const ORDER_ENDPOINT = 'https://kurferma-proxy.ВАШ-АДРЕС.workers.dev';
```

После этого **удалите** из этих двух файлов строки с `TG_TOKEN` и `TG_CHAT` —
они больше не нужны, токен теперь живёт только на сервере.

Готово: форма работает как раньше, но токена в коде сайта больше нет.
