# Каталог кур (мобильная версия)

Простой каталог-витрина без сборки: открой `katalog/index.html` — и всё работает
(локально с диска или на любом хостинге статики, например GitHub Pages).

Структура навигации: **Порода → Окрас → Объявление** (фотогалерея со свайпом,
заголовок, описание).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Страница-приложение (вёрстка, стили, логика). Обычно трогать не нужно. |
| `data.js` | **Все данные каталога** — породы, окрасы, номера фото, описания, цены. Редактируется руками. |
| `photos/` | Папка с фотографиями. |

## Как добавить фото

Просто положи файл в папку `photos/` с именем-номером: `600.jpg`, `785.jpg` и т.д.
Подойдут `.jpg`, `.jpeg`, `.png`, `.webp`. Сайт подтянет фото автоматически —
пока файла нет, на его месте серый placeholder с этим номером.

## Как добавить описание

В `data.js` найди нужный окрас и впиши текст:

```js
{ id: "belaya", name: "Брама белая", photos: [600, 602], description: "Молодки 4 мес., привиты.", price: null },
```

## Как добавить цену (позже, по прайсу)

Там же впиши цену строкой — она сразу появится на странице объявления:

```js
{ ..., price: "3 500 ₽" },
```

Пока `price: null` — цена нигде не показывается.

## Как добавить окрас или породу

Скопируй существующий блок в `data.js` и поменяй значения. Поле `id` — латиницей,
без пробелов, уникальное внутри породы (оно попадает в адрес страницы).
